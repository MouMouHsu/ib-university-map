# IB 文憑生的全球大學申請地圖

給 IB 文憑生與家長使用的單頁網站，整理英國、美國、加拿大、澳洲、香港、新加坡、日本、歐洲共 31 所承認 IB 的大學，以 2027 年入學為目標。

## 功能

- 輸入預估 IB 總分，自動標示各校落點：穩上、適配、挑戰、差距大；不設 IB 最低分的學校 (如美國) 標示為綜合評估
- 依區域、想讀的領域、落點、每年總預算 (新台幣) 與關鍵字篩選
- 每校列出 IB 分數與 HL 要求、特色科系、國際生學費、生活費、申請截止日與官網連結
- 最多 3 校並排比較
- 申請截止日時間軸，14 天內截止的學校會特別標示
- 匯率可自行調整，設定保存在瀏覽器

## 資料說明

- 資料整理日：2026-11-21
- 標示「官方」的數字已對照學校官網；標示「估」的是參考值
- 學費與錄取分數每年調整，且同校不同科系差異很大，正式申請前請以各校官網為準
- 英國、加拿大、澳洲的生活費採各國學生簽證的最低財力證明金額；美國採學校公布的就學總花費扣除學費

## 使用方式

整個網站只有 `index.html` 一個檔案，不需要安裝任何東西，用瀏覽器直接開啟，或透過 GitHub Pages 瀏覽即可。
